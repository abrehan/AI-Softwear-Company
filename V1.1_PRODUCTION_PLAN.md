# AI Software Company v1.1 Production Plan

## Goal
Move the v1.0.0 validated backend toward repeatable production delivery without weakening the existing QA release gate.

## Included in this foundation
- GitHub Actions backend compilation/import/OpenAPI quality gate.
- Production backend Docker image definition.
- Docker build context protection through `.dockerignore`.
- Release branch: `v1.1-production-foundation`.

## Required before v1.1.0 release
- Configure production secrets through the deployment platform; never commit `.env` or credentials.
- Select the production host and configure HTTPS.
- Configure a persistent production database and migrations.
- Configure Ollama/LLM access appropriate for the production environment; local `127.0.0.1:11434` must not be assumed in production.
- Add authenticated endpoint smoke tests against the deployed service.
- Add frontend build/deployment validation.
- Add rollback procedure and deployment health check.
- Run the full QA agent release gate after deployment.

## Release gate
A v1.1.0 release should require:
1. CI green.
2. Docker build succeeds.
3. Production health endpoint returns HTTP 200.
4. OpenAPI endpoint is available.
5. Authentication smoke test passes.
6. No secrets are present in repository history or deployment artifacts.
7. QA Agent reports RELEASE_READY.
